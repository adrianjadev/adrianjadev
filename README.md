## Focus & Engineering Approach

I build, harden, and automate cloud environments with a focus on **Google Cloud Platform (GCP)**, **Infrastructure as Code (IaC)**, and **DevSecOps** workflows. My work centers on shifting security left—enforcing least-privilege IAM, network segmentation, and reproducible Terraform deployments so security is built into the pipeline rather than bolted on afterward.

- **Cloud Security:** IAM governance, Zero-Trust architecture, SSO/identity federation, VPC network hardening, and risk management
- **DevOps & IaC:** Modular Terraform deployments, state management, and repeatable cloud architectures
- **Containers & Workloads:** Kubernetes (GKE) fundamentals, workload isolation, and hardened configurations
- **Hands-On Portfolio:** Translating real-world cloud & security engineering labs into clean, sanitized, reusable GitHub repositories
